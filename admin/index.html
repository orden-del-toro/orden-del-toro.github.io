Orden del Toro

Administrá la página desde tu celular o computadora. Los cambios se guardan en GitHub y podés publicarlos desde acá.

Ingresala únicamente en esta página. Se usa durante esta pestaña y se elimina al salir; no se guarda en el navegador.

Configurar el acceso por primera vez
  1. Abrí crear credencial en GitHub con tu cuenta Rupp-ar.
  2. En Repository access, elegí Only select repositories y seleccioná admin-privado y orden-del-toro.github.io, de la organización orden-del-toro.
  3. En permisos, verificá Contents: Read and write. Luego tocá Generate token.
  4. Copiá la credencial y pegala en el campo de arriba. GitHub la muestra una sola vez: podés conservarla en tu gestor de contraseñas.

Solo tu cuenta tiene acceso al panel privado. Cuando venza la credencial, podés crear otra desde el mismo enlace.
